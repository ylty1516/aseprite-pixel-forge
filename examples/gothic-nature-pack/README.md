**与 L3（商业成品）的差距（诚实记录）：**
1. 细节层次：树皮纹理、叶簇的分形式层次不如手绘，1x 下"有点像"但缺乏炫技细节；
2. 拱残件形状结构弱（弧段像"月牙"），需要更复杂的砌块分解重写；
3. 草地 tile 均匀度高，缺乏手工摆放的草簇节奏；
4. 无动画（摆动/风吹）——路线图 v3；
5. 树木种类偏少（3 类），够垂直切片用，不够一整个游戏。

**下一步建议：** ① 用 `forge evolve` 对每类做 2 轮进化再筛（本包含手工看片选优，等价一轮）；② 拱残件配方重写（砌块分解）；③ 人物/建筑品类按 v2 路线开发。

## 复现

```bash
py -3 scripts/forge.py gen tree --style styles/left-hand-of-god.json --out build/tree --count 16 --seed 5000
py -3 scripts/forge.py check build/tree
py -3 scripts/forge.py preview build/tree --scale 4 --cols 8
py -3 scripts/forge.py export build/tree --out out --pick <预览序号> --sheet
```
（各品类 seed：tree/bush/rock=5000，flower/tile/ruin=6000，草地补充=7000）

## Godot 导入建议

1. 导入设置：Filter = **Off**、Mipmaps = Off、Fixed Size；
2. 图集：`*_sheet.json` 的 `frames` 为 `{名称: {x,y,w,h}}`，可直接喂给 SpriteFrames/AtlasTexture 脚本；
3. 世界渲染 480×270、整数倍缩放（沿《神之左手》规格）。
