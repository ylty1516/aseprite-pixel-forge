# 像素画技法规则（程序化绘制的"判断力"来源）

本文件把专业像素画的判断规则编码为可执行的约束。生成器代码必须服从；评审时逐条对照。

## 1. 色板纪律

- **只用 style spec 中的色阶**（ramp）：每条 ramp 是同一材质的暗→亮 5 阶。禁止任意 RGB。
- **色相偏移**：暗部向冷（蓝紫）偏、亮部向暖偏（冷材质如铁/霜相反，亮部向冷白偏）——本库色板已按此设计，直接使用即可。
- **单材质单 ramp**：一件物件的同一材质只从一条 ramp 取色（树干= bark，石= stone），不同材质各自 ramp。
- **禁用纯黑/纯白**：最暗用 shadow/outline 色，最亮用 ramp 顶阶。
- **禁止半透明/AA**：像素画全部不透明或全透明；边缘不做抗锯齿。

## 2. 光照一致性

- 全局单一光源：style spec 的 `lighting.direction`（默认左上）。
- 光侧（左上）亮阶、影侧（右下）暗阶；底部/右侧内缘再压暗一档（AO 带）。
- 高光只出现在朝向光源的上表面/上缘，且**成簇**出现（2×2 或短线），不做单像素撒盐。

## 3. 簇（cluster）纪律

- 明暗块以 2×2 为最小思考单位；禁止大面积孤立单像素抖动。
- 抖动（dither）只用于两阶过渡带，Bayer/棋盘均可；`density` 连续 0–1，推荐 25%/50%/75% 三档，不滥用。
- 边界扰动（perturb）后必须清理：移除孤立像素（<2 邻居）、填补大凹洞（≥6 邻居）——`px.despike` 已实现。

## 4. 轮廓策略

- selective（默认）：影侧（右下）实线，光侧（左上）断线（约 45% 断续），颜色= 全局 outline 色。视觉上"融进背景"。
- full：全周实线（小型物件/道具）。
- none：tile 类满画布物件不描边。
- 轮廓画在形状外侧（扩张 1px）；花瓣等细枝末节要并入 mask 再描边，避免"漂浮像素"。

## 5. 形体与反模式

- **先剪影后细节**：拿掉颜色单看 mask，应当可辨识（剪影测试）。
- 破除几何感：形状用 `blob`（径向噪声）而非完美圆/矩形；建筑直角物体可保留直线，但边缘加 1px 扰动/缺损。
- 反模式清单（评审必查）：
  - 单像素撒盐（无簇逻辑的随机点）
  - 完美对称的圆锥/圆球（除非风格要求）
  - 直线边缘贯穿全图（"蛋糕层"）
  - 高光在影侧 / 光色矛盾
  - 同材质跨 ramp 串色
  - 触边细节被裁掉（除 tile）

## 6. 1x 可读性（最高优先）

- 成品必须在 1x（不放大）下可辨识；放大图只用于工作检查。
- 评审时同时看 6x 和 1x（联系表已并排两种视图）。
- 若 1x 下剪影糊成一团 → 增大明暗对比或简化内部细节，而非增加细节。

## 7. 确定性

- 所有随机必须走注入的种子 PRNG（`ctx.rng`）；禁止 `os.time`/全局随机。
- 同一 seed + 同一参数 + 同一 style ⇒ **图像逐字节相同**（manifest 含创建时间戳与键序差异，不影响图像字节；以 PNG sha256 为准）。这是可复现性与"进化"机制的基础。

## 8. 动画纪律（多帧配方）

- **剪影必须先于运动**：相邻帧的轮廓要真实变化（树冠重心移、枝叶孔洞换位、叶片弯曲），整体平移不是动画。
- **根部固定**：树干/草根用 pivot 锚定不动，运动幅值随高度递增（`px.shear` 的 falloff 自动处理）。
- **帧数 4–6、幅值 1–3px**：循环动画的舒适区；帧太大幅值太大就变成“抽搐”。
- **循环无缝**：首尾帧相位差 = 2π 整数分；同 seed 逐帧重建保证基础形态一致（只在相位上变化）。
